ISHARA is a real-time accessibility tool that translates sign language hand gestures and facial expressions into spoken sentences. Designed to bridge the communication gap between Deaf, hard-of-hearing, and hearing communities, ISHARA delivers real-time translation in both English and Nepali.

🚀 Key Features
Real-Time Hand Gesture Detection: Tracks 21 3D hand landmarks per hand to capture sign language gestures instantly.

Facial Emotion Recognition: Captures facial mesh landmarks to incorporate emotional context into translated phrases.

Bilingual Support (English & Nepali): Translates recognized sign sequences into natural, grammatically correct sentences in both English and Nepali.

Speech Synthesis: Uses browser-native Web Speech APIs to vocalize translated text seamlessly for real-time auditory output.

Modern & Responsive UI: Styled with Tailwind CSS for a sleek, responsive interface across desktop and mobile browsers.

Frontend & UI
